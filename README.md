# 🏋️ My WorkOut

**My WorkOut** is a comprehensive, full-stack gym management application designed to streamline administrative workflows and enhance the fitness center experience for both gym owners and members. 

Built as a Progressive Web App (PWA), it delivers a seamless, app-like experience across both web and mobile platforms.

## 🚀 Features

### For Administrators
* **Member Management:** Securely add, edit, and remove gym members from the system.
* **Attendance Tracking:** Dedicated admin modules to log and monitor daily member attendance.
* **Financial Dashboards:** Track payments, manage membership fees, and monitor outstanding balances.
* **Event Management:** Create and manage special gym events and announcements.

### For Members
* **Personalized Dashboard:** Members can log in to view their active membership status and track their own daily attendance.
* **Workout Tracking:** Access daily workout routines and training plans directly from the portal.
* **Mobile-Ready:** Fully responsive design that installs natively on mobile devices via PWA service workers.

## 💻 Tech Stack

* **Frontend:** React, Tailwind CSS, HTML/CSS
* **Backend:** PHP
* **Database:** MySQL
* **Architecture:** Progressive Web App (PWA) utilizing `manifest.json` and Service Workers (`sw.js`) for offline capabilities and mobile installation.
